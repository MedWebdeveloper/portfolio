# NewStart Ontario — Services Navigator

NewStart Ontario is a bilingual, accessible service-navigation concept that helps newcomers find relevant support and turn fragmented information into a clear settlement plan.

## Interactive demo

https://medardkiteretse.com/projects/newstart-ontario/

## The problem

Newcomers often need employment, housing, healthcare, language, legal and family services at the same time. Information is distributed across many organizations, eligibility rules can be difficult to interpret, and the next step is rarely obvious.

## What I designed and implemented

- Four-step guided needs assessment
- Personalized settlement-plan output
- Six service categories
- Desktop and mobile responsive states
- Bilingual interface foundation
- Accessible semantic structure and keyboard-friendly controls
- Maple-leaf visual identity
- Reusable Figma components, variants and Auto Layout

## Figma evidence

- 15 reusable design variables
- Button variants: primary, secondary, default and disabled
- Choice-card variants: default and selected
- Desktop home screen
- Guided navigator state
- Mobile home screen
- Developer-ready typography and color foundations

## Implementation

- Semantic HTML
- Responsive CSS
- Vanilla JavaScript state management
- Native dialog-based guided flow
- No external runtime dependency
